## 🏛️ Project Overview

The **Real Estate Management System** is a Java-based desktop application developed using Java Swing for its graphical user interface and MySQL for database management.

The system provides a centralized platform for managing property listings, buyer and seller information, and real estate transactions.

Using JDBC connectivity and the XAMPP server, the application performs database operations efficiently, helping users maintain organized property records through an interactive interface.

> **Manage Properties. Connect People. Simplify Transactions.**

## 🔄 How the System Works

```text
       USER
         |
         ▼
  Java Swing Interface
         |
         ▼
     JDBC Layer
         |
         ▼
    MySQL Database
         |
         ▼
   Store / Retrieve
      Records
```

1. Users interact with the application through the Java Swing interface.
2. JDBC establishes a connection between Java and MySQL.
3. Users perform CRUD operations on the available modules.
4. MySQL stores and manages the application records.
5. Updated information is retrieved and displayed through the GUI.

## 🚀 Installation & Setup

Follow these steps to run the project locally:

**1. Install XAMPP**

Download and install XAMPP, then start the MySQL service.

**2. Create Database**

Open phpMyAdmin and create a database named:

```sql
CREATE DATABASE real_estate_db;
```

**3. Import Database**

Import the project's SQL file into the newly created database, if provided.

**4. Open Project**

Open the Java project in NetBeans or another compatible Java IDE.

**5. Configure JDBC**

Add the MySQL JDBC Connector to the project libraries and configure the database connection credentials.

**6. Run Application**

Execute the main Java class to launch the Real Estate Management System.
